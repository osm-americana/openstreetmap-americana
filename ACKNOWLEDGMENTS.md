# Acknowledgments

OpenStreetMap Americana is only possible due to the sustained efforts of open data and open source communities. OHM Americana is heavily based on [OpenStreetMap Americana](https://github.com/osm-americana/openstreetmap-americana/). [OpenStreetMap U.S.](https://openstreetmap.us/), OpenStreetMap’s local chapter in the United States, supports OSM Americana as a community project and serves as a fiscal host for OHM. You can support the work we do by [donating to OHM through OpenStreetMap U.S.](https://donate.openhistoricalmap.org/)

## Data sources

The style is compatible with [OpenHistoricalMap’s official vector tiles](https://wiki.openstreetmap.org/wiki/OpenHistoricalMap/Reuse#Vector_tiles).

The legend’s “Route markers” section is labeled using labels of Wikidata items that are tagged with the [corresponding OSM tag](https://www.wikidata.org/wiki/Property:P1282).

## Design

- The stylized highway shields are inspired by "[Rebusurance](https://github.com/1ec5/rebusurance/)" by Minh Nguyễn.
- The route shield for New Mexico state routes incorporates a Sun Symbol [courtesy of the Pueblo of Zia](https://github.com/osm-americana/openstreetmap-americana/pull/323#issuecomment-2083591746).
- The font stack was [packaged from Google Fonts](https://fonts.google.com/attribution).

## Code

- Initial layer code is derived from Oliver Wipfli's [openmaptiles-starter](https://github.com/wipfli/openmaptiles-starter/) style.
- Support for right-to-left Arabic and Hebrew text is provided by the [mapbox-gl-rtl-text](https://github.com/mapbox/mapbox-gl-rtl-text/) plugin.
- The time control is powered by the [Timescope](https://xenodrive.github.io/timescope/) library.
